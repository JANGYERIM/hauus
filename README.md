# HAUUS Revisit Reminder Agent

수원 영통 속눈썹 샵 **하어스(HAUUS)** 를 위한 재방문 리마인드 에이전트.
네이버 예약 엑셀 한 번 업로드 → 안 돌아온 손님 자동 추출 → 시술별 문구 초안 → 사장님이 복사해 카톡/문자로 발송.

Track B 개인 프로젝트 · 경희대 2026-2

## 구성

| 경로 | 무엇 | 주소 |

| `owner/index.html` | **사장님용** 재방문 관리 앱 (엑셀 업로드, 리마인드, 손님 메모, 재고, 통계) | `https://<아이디>.github.io/<레포>/owner/` |

## 사장님 사용법 (주 1회, 5분)

1. 네이버 스마트플레이스 → 예약 관리 → 엑셀 다운로드
2. `owner/` 페이지 → **엑셀 올리기** (이미 있는 예약은 자동으로 건너뜀)
3. **오늘** 탭에서 손님별 문구 **복사** → 카톡/문자로 전송 → **보냄 처리**

손님은 문구 속 링크로 `index.html`을 열어 관리법·영양제 재고·네이버 예약 버튼을 봄.

## 데모 흐름 (11/23 기준)

1. 설정 → 모든 기록 지우기 → 시술 기록 탭 → **샘플 데이터 넣기** → 오늘 탭에 리마인드 대상 25명
2. 오늘 탭 → **안 보낸 손님 전부 보냄 처리** → 25명 보냄
3. **엑셀 올리기** → `네이버예약_예약목록_하어스_20261001-20261207.xlsx` → 예약확정 13건 등록
4. 통계 탭 → 리마인드 보낸 25명 중 **예약·재방문 11명**

예약확정(아직 안 온 예약)은 방문·매출에 넣지 않고, 손님 옆에 `예약 MM/DD` 로 표시되며 리마인드 대상에서 빠짐. 오늘부터 두 달 뒤까지의 예약만 화면에 보임. 같은 예약번호가 나중에 이용완료·취소로 바뀌어 올라오면 상태가 갱신됨.

## 고객 페이지 링크 규칙

`index.html#<시술>-a<재고>-b<재고>`
- 시술: `perm` 펌 / `ext` 연장 / `touch` 리터치 → 해당 탭이 열림
- 재고: `2` 있음 / `1` 소량 / `0` 품절 (a = 마스카라 에센스, b = 듀얼)
- 사장님 앱의 제품·재고 탭에서 바꾸면 문구 속 링크가 자동으로 바뀜

## 설계 (5칸)

| | |
|---|---|
| 입력 | 네이버 예약 엑셀 (예약자명·연락처·예약상품·이용일·예약상태) |
| 처리 | 이용완료만 집계 → 손님별 마지막 방문 → 시술별 기준(펌 5주 / 연장·리터치 3주) 초과 & 미발송 추출 → 템플릿으로 문구 |
| 사람 승인 | 사장님이 문구를 보고 복사해 직접 발송 (아무것도 자동으로 손님에게 가지 않음) |
| 출력 | 카톡/문자 + 고객 케어 페이지 링크 + 네이버 예약 링크 |
| 실패 시 | 컬럼 못 찾으면 안내 토스트, 취소·노쇼는 리마인드 제외, 데이터 없으면 빈 화면 안내 |

## 배포 (GitHub Pages)

1. 이 폴더를 레포 루트에 올림
2. Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `/ (root)` → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<레포>/` 로 접속
4. 사장님 앱 → 설정 → **고객 케어 페이지** 칸에 그 주소 입력

## 개인정보

- 손님 이름·연락처는 사장님 기기에만 저장
- 고객 페이지 링크에는 개인정보가 들어가지 않음 (시술 종류·재고만)
- 프로젝트 종료 시 학생 접근 권한 회수, 샘플 데이터는 전부 허구
