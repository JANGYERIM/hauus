# HAUUS 재방문 리마인드 — n8n 설정 가이드

워크플로 3개를 n8n에 Import 하고, 인증 정보 3개만 연결하면 됩니다.

## 0. 준비물 (한 번만)

1. **텔레그램 봇** — 텔레그램에서 `@BotFather`에게 `/newbot` → 봇 이름 정하기 → 토큰 받기.
   사장님이 봇에게 아무 말이나 한 번 보내면, `https://api.telegram.org/bot<토큰>/getUpdates` 를 브라우저로 열어 `chat.id` 숫자를 확인 (= 사장님 chat_id).
2. **구글시트** — 새 시트 하나 만들고 탭 2개:
   - `시술기록` 1행 헤더: `예약번호 | 이용일 | 고객명 | 연락처 | 시술 | 상태 | 금액 | 메모`
   - `보냄기록` 1행 헤더: `고객명 | 연락처 | 보낸날 | 처리`
   - 시트 URL의 `/d/` 뒤 긴 문자열이 시트 ID.
3. **Anthropic API 키** — console.anthropic.com에서 발급.

## 1. n8n에 넣기

1. n8n → 워크플로 목록 → `Import from File` → 3개 JSON 차례로.
2. **Credentials** 메뉴에서 만들기:
   - Telegram API: 봇 토큰
   - Google Sheets OAuth2: 구글 로그인 (사장님 시트에 접근 권한 있는 계정)
   - Header Auth: Name `x-api-key`, Value = Anthropic 키
3. 각 워크플로에서 `REPLACE` 로 된 곳 바꾸기:
   - 구글시트 노드 → Document ID: 시트 ID
   - 텔레그램 보내기 노드 → Chat ID: 사장님 chat_id
   - 각 노드의 Credential 드롭다운에서 위에서 만든 것 선택
4. 워크플로 3개 모두 오른쪽 위 **Active** 켜기.

## 2. 흐름

| 워크플로 | 트리거 | 하는 일 |
|---|---|---|
| 1 엑셀 올리면 시술기록 등록 | 사장님이 봇에 엑셀 파일 전송 | 네이버 컬럼 자동 인식 → `시술기록` 탭에 예약번호 기준 중복 없이 저장 → "N건 반영" 답장 |
| 2 월요일 리마인드 | 매주 월 09:00 | 이용완료만 집계 → 5주+ & 이후 방문 없음 & 미발송 손님 추출 → Claude가 문구 → 사장님 텔레그램에 [보냄 처리 / 건너뛰기] 버튼과 함께 전송 |
| 3 승인 버튼 응답 | 버튼 클릭 | `보냄기록` 탭에 기록 → 같은 손님에게 다음 주 또 안 보냄 → 메시지에 처리 결과 표시 |

v1에서는 사장님이 텔레그램 문구를 복사해 카톡/문자로 직접 보냅니다. (자동 발송은 3주차 SMS API 추가 시)

## 3. 테스트 순서

1. 워크플로 2를 열고 **Test workflow** 눌러 수동 실행 → 텔레그램에 카드 오는지 확인.
   (`네이버예약_예약목록_하어스_20261001-20261101.xlsx`를 먼저 봇에 보내 두면 데이터가 생김)
2. 버튼 눌러보기 → `보냄기록` 탭에 한 줄 생기는지 확인.
3. 다시 Test workflow → 방금 처리한 손님은 안 오는지 확인.

## 4. 자주 걸리는 것

- **텔레그램 트리거가 안 옴**: n8n이 공개 URL(https)이어야 함. 로컬이면 n8n cloud 쓰거나 ngrok 같은 터널 필요.
- **트리거 2개가 같은 봇**: 워크플로 1(message)과 3(callback_query)이 같은 봇을 쓰면 n8n은 보통 마지막에 켠 것만 웹훅으로 잡음. 안 되면 워크플로 1과 3을 하나로 합치고 트리거 updates를 `message, callback_query` 둘 다 선택한 뒤 IF로 나누면 됨.
- **Claude 모델명**: `claude-sonnet-4-5`가 안 되면 콘솔에서 현재 모델명 확인 후 HTTP 노드 Body에서 교체.
- **5주 기준 바꾸기**: 워크플로 2 → `리마인드 대상 계산` 노드 첫 줄 `WEEKS=5`.
- **Google Sheets `read`가 빈 결과**: 탭 이름이 정확히 `시술기록`, `보냄기록`인지 확인.
